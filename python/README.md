# Python Learning Path

Python fundamentals through topic-based practice labs, short programs, and focused exercises.

## Contents

### Fundamentals

Work through the topics in order:

1. `1-variables-datatypes/`
2. `2-strings/`
3. `3-lists-tuples/`
4. `4-dict-sets/`
5. `5-conditionals/`
6. `6-loops/`
7. `7-functions-recursion/`
8. `8-file-io/`
9. `9-oop/`

### Additional Practice

- `python-core-topics.md` — short programs covering variables, conditionals, functions, lists/tuples, dictionaries, iteration, file handling, regex, and a basic networked request

### Tools

- `tools/exception-handling/` — focused practice with `try`/`except`/`finally`
- `tools/todo-list-manager/` — a small menu-driven CLI to-do list app (add/view/update tasks), practicing functions and program structure beyond single-topic exercises

## Suggested Path

```text
Syntax & data types
        ↓

        ↓
Conditionals & loops
        ↓
Functions & recursion
        ↓
Files & OOP
        ↓
Exception handling & practical programs
```
