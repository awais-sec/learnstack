# TO-DO List Manager

A command-line to-do list application that lets you add, view, and update
tasks with status tracking (Pending/Completed).

## What It Demonstrates

- Functions organizing a small interactive program around shared state
  (a list of task dictionaries).
- A menu-driven loop (`while True`) with input validation.
- Basic CRUD-style operations (add, view, update) on in-memory data.

This is a **Python fundamentals project**, not a security tool.

## Requirements

- Python 3
- No external packages are required.

## Usage

```bash
python todo_list.py
```

```text
Simple To-Do List
1. Add Task
2. View Tasks
3. Update Task
4. Exit
Choose an option:
```

## Skills Demonstrated

- Functions and program structure
- Lists of dictionaries as simple in-memory records
- Menu-driven CLI loops
- Input validation with `try`/`except`
