# LearnStack

A practical learning archive for building programming and scripting foundations through hands-on work.

This repository is intentionally different from my security-tools repository: **LearnStack contains learning exercises, coursework practice, and small programs used to understand concepts.** It preserves the progression from fundamentals to practical scripting rather than presenting every exercise as a finished tool.

## Learning Paths

### Python

Practice Python fundamentals through topic-based labs and short core-topic programs.

- [Python learning path](python/README.md)
- Variables & data types
- Strings
- Lists & tuples
- Dictionaries & sets
- Conditionals
- Loops
- Functions & recursion
- File I/O
- Object-oriented programming
- Exception handling
- Small CLI tools (to-do list manager)

### Shell Scripting

Twelve practical labs progressing from basic shell usage into scripting and system-oriented tasks.

- [Shell scripting labs](shell/README.md)
- Shell fundamentals
- Variables and arguments
- File tests and wildcards
- Conditionals and loops
- Functions and libraries
- Arrays
- Process management
- File operations

## How to Use This Repository

The material is organized as a learning path rather than a single application. Start with the fundamentals, work through the labs in order, and use the individual README files and examples as references when revisiting a topic.

```text
LearnStack
├── Python fundamentals
│   ├── Core syntax and data structures
│   ├── Control flow and functions
│   ├── Files and OOP
│   └── Exception handling
└── Shell scripting
    ├── Command-line foundations
    ├── Script construction
    ├── Control flow and functions
    └── System/file/process operations
```

## Intended Audience

Useful for students, beginners, and anyone who wants practical examples while learning Python or shell scripting. The material also provides a record of the programming and scripting practice behind my cybersecurity work.
